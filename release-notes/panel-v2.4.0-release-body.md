## 安装

```
curl -fsSL https://github.com/akari-projectX/akari-panel/releases/download/v2.4.0/install.sh | sh
```

支持 Debian 12/13、Ubuntu 22.04/24.04；Docker 部署见 `docs/DEPLOY.md`，镜像（`deploy/.env` 的 `AKARI_IMAGE`）：

```
ghcr.io/akari-projectx/akari-panel:2.4.0@sha256:REPLACE-WITH-THE-RELEASE-DIGEST
```

使用前请按 `docs/DEPLOY.md`「Verify a release」校验签名。

本版主要是用户门户的新外观「纸面简约」，另有两项新功能：仪表盘活动位与用量导出。

## 新功能
- **仪表盘活动位（限时活动）**：后台「内容 › 活动」新建活动：标题、一句说明、折扣字样（如「8折」）、可选关联优惠券、按钮文字与链接、开始与结束时间、受众（全部 / 有套餐 / 无套餐）、排序、启用开关，编辑时右侧实时预览。门户仪表盘右侧显示当前可见的一个活动（排序大者优先，其次最先结束），按面板时钟倒计时；关联的优惠券仍可用时显示券码并可一键复制，券停用或用完则不显示券码。没有活动或活动结束时这一栏不出现。
- **用量导出 CSV**：门户「用量」页「明细记录」右上角「导出 CSV」，导出所选日期范围的每日记录（日期、下行 / 上行 / 合计 / 计费字节，以及合计与计费 GB），Excel 直接打开不乱码。

## 门户：新外观「纸面简约」
- 整体换成纸白底色、细线与黑色强调色，深色模式同步调整。
- 顶栏改为主导航 + 右侧头像菜单（账户信息、钱包、设置、退出登录）；手机上为折叠菜单。
- 页脚改为大号空心的站点名称字样（站点名称为 Akari 时是专门绘制的轮廓字）、版权行与条款 / 隐私 / 自定义链接。
- 仪表盘重新排版：剩余流量、到期、线路、公告与动态、活动位分区展示。
- 其余各页（商店、订单、线路、用量、钱包、工单、帮助、设置等）统一新的页标题、卡片、表格与按钮样式；钱包页标题下不再重复显示余额。
