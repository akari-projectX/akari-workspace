> **可以从 v2.2.0 原地升级**（`akari-ctl upgrade`，无需重装）：本版没有数据库迁移，升级前安装器会先备份。
>
> **节点：不需要升级 agent。** 协议号仍为 8，v0.6.x 的 agent 照常工作；建议节点用 agent v0.6.3（修复了自更新器可能被卡住的问题，并有性能改进）。

## 安装

```
curl -fsSL https://github.com/akari-projectX/akari-panel/releases/download/v2.2.1/install.sh | sh
```

支持 Debian 12/13、Ubuntu 22.04/24.04；Docker 部署见 `docs/DEPLOY.md`，镜像（`deploy/.env` 的 `AKARI_IMAGE`）：

```
ghcr.io/akari-projectx/akari-panel:2.2.1@sha256:6a00e0c423d77a1ac21fa21b64b9e958c69d7d00ace518a0f73fff2a3ec9032f
```

使用前请按 `docs/DEPLOY.md`「Verify a release」校验签名。

本版是一次全面的安全测试（红队）之后的修复版，外加门户的细节修整。测试没有发现严重或高危问题。

## 安全修复

### 登录
- 「仅通行密钥账户」的「发送邮箱验证码」现在与登录用同一套防机器人检查（蜜罐、最短提交时间、Turnstile）。之前它会对密码对错给出不同回答，可以被用来批量试密码。
- 管理员在门户首页输入正确密码时，登录限速按「密码错误」计数（之前会退还名额，试 20 次就能看出密码是否正确）。

### 支付与资金
- Coinbase、CoinPayments 的 Webhook 密钥至少 16 位。**已保存的更短密钥会显示为「无法读取」，请所有者在支付方式里重新填写**，否则该方式的回调验签会失败。
- 先只退钱（保留套餐）再退换套餐的订单时，不再把已退款的旧套餐恢复回来。
- 迟到的付款到账时，如果下单时用的优惠券已满或换套餐抵扣已失效，不再开通，整笔退回余额并通知（`order_admin.stale_terms`）。
- 人工订单（后台「人工订单」与「标记已付款」）不再产生邀请返利。
- 退款确认框会提示「这笔订单的价值已被后续换套餐抵扣」，并列出相关订单。
- 超大的支付回调请求与普通拒绝的回答完全相同，不再暴露回调接口。
- 审计保留期设为「永久」时，未验签的支付事件也会在 90 天后清理（之前会永远保留）。
- 批量优惠码至少 10 位随机字符。
- 恢复被换掉的旧套餐时，扣除其间已退款的续费时长。

### 节点与更新
- 同一台服务器同时只能占用一个下载名额：一台被攻破的节点不能再占满名额、让全网节点拿不到 agent 更新或无法安装。
- 节点上报的版本号、平台等文字有长度上限，不能再撑大数据库与后台列表。
- （需 agent v0.6.3）节点上的自更新器不会再因为 agent 目录里被放了同名目录而反复启动、最终被 systemd 停掉。

### 后台权限与内容
- **面板自己依赖的 DNS 记录**（主域名、订阅域名、节点通信域名、通行密钥中心域名、服务器证书域名、入口连接地址）的新增、修改、删除，以及「指向本面板」，**只有所有者能操作**；其他管理员在这些地方只读。其他 DNS 记录不受影响。
- 自定义邮件模板的 HTML 里，验证码与重置链接（`{code}`、`{link}`）只能写在正文文字或 `<a href>` 里，写在图片地址、样式等位置会被拒绝保存。原因：邮件客户端加载图片时会把它们发给外部服务器。已经保存的模板照常发送，下次修改保存时才检查。
- 邮件模板 HTML 的安全检查不再能用字符实体或 CSS 转义绕过（如 `jav&#x61;script:`）。
- DNS 记录名写成相对形式（`@`、`panel`）时，同样会提示「该记录被面板使用」。

## 门户
- 未登录时的隐私政策、服务条款、登录、注册等页面在手机上不再贴边，与登录后的页面边距一致。
- 确认对话框：标题与说明分开显示，图标底色与图标颜色一致；「重置订阅」「注销账户」等对话框的说明不再重复列表内容。
- 页脚和区块标题旁的链接与内容右边对齐；手机上小按钮与文字链接的点按区域加大到约 40px。
- 工单列表在手机上只显示「分类 · 更新时间」。
- 套餐已到期或流量已用完的用户，「已用流量」卡片写明原因（不再显示「购买套餐后可用」）。
- 设置页「订阅链接」下的一行改名为「链接状态」。
- 仪表盘的线路倍率标签与线路页同色。
- 其他：邀请页「复制链接」改用链接图标；用量页数字与单位不再断开；帮助分类名过长时换行显示。
