> **可以从 v2.4.x 原地升级**（`akari-ctl upgrade`，无需重装）：本版只改用户门户的界面，没有数据库迁移，升级前安装器会先备份。
>
> **节点：不需要升级 agent。** 协议号仍为 8，v0.6.x 的 agent 照常工作；建议节点用 agent v0.6.3。

## 安装

```
curl -fsSL https://github.com/akari-projectX/akari-panel/releases/download/v2.5.0/install.sh | sh
```

支持 Debian 12/13、Ubuntu 22.04/24.04；Docker 部署见 `docs/DEPLOY.md`，镜像（`deploy/.env` 的 `AKARI_IMAGE`）：

```
ghcr.io/akari-projectx/akari-panel:2.5.0@sha256:REPLACE-WITH-THE-RELEASE-DIGEST
```

使用前请按 `docs/DEPLOY.md`「Verify a release」校验签名。

本版把用户门户除仪表盘外的全部页面按仪表盘的风格重新排版。v2.4.0 只给这些页面换了配色与页头，里面还是旧版式。

## 门户：所有页面统一成仪表盘的样子
每页都是：一行小字页名、一句大字说明现在的状况、右侧一行补充，下面是胶囊筛选与一整块细线内容。

- **商店**：套餐分列、列间细线；只有一个套餐时占满一行（右边是说明清单），两个时各占一半。底部一行价格说明。
- **线路**：「N 条线路，M 条在线」+ 自动刷新时间与刷新按钮；按入口标签筛选；一张线路表（与仪表盘底部同一张），倍率列可切换排序，表下是负载图例。
- **用量**：「本期已用 X / Y GB」+ 本月 / 近 7 天 / 近 30 天；三个数字（今日、这段时间与日均、计费）；每日柱状图（与仪表盘同一张）；按线路；明细与「导出 CSV」。
- **订单**：状态筛选 + 一张表，待支付的订单直接「取消」「去支付」。
- **钱包**：「余额 ¥x」，三个数字（余额、可提现、待结算）；邀请好友与余额明细左右两栏；返佣、收支流水、提现记录三个分页在下面。
- **公告**：「N 条公告还没看」，按标签筛选；置顶公告大字显示，其余是细线列表。
- **工单**：页头右侧「提交工单」，按状态筛选（带数量），细线列表。
- **设置**：页头是登录邮箱；分区导航是一排胶囊，滚动时固定在顶部；每项设置占一整行。
- **文档、登录与注册**：换了新的页头；文档页底部加「找不到答案？提交工单」。

## 去掉的内容
- 页脚上方的大号空心站点名（页脚只剩一道细线与版权、链接）。
- 商店页的「当前订阅」区（剩余天数大字、流量条、到期 / 速率 / 余额）。流量重置包改为套餐下面单独一行；流量用完时当前套餐的按钮就是重置包。
- 各页顶部的统计格子；线路页的搜索框；用量页的面积图、环形图与计费柱状图；公告页的按月时间线。
