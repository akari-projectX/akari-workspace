> **可以从 v2.6.x 原地升级**（`akari-ctl upgrade`，无需重装），升级前安装器会先备份。本版只改用户门户的界面，没有数据库迁移。
>
> **节点：不需要升级 agent。** 协议号仍为 8，v0.6.x 的 agent 照常工作；建议节点用 agent v0.6.3。

## 安装

```
curl -fsSL https://github.com/akari-projectX/akari-panel/releases/download/v2.6.1/install.sh | sh
```

支持 Debian 12/13、Ubuntu 22.04/24.04；Docker 部署见 `docs/DEPLOY.md`，镜像（`deploy/.env` 的 `AKARI_IMAGE`）：

```
ghcr.io/akari-projectx/akari-panel:2.6.1@sha256:843ff8bc692052ac8ec10c11d4bcdcfcf832202879e5f98fffbc54fb2cbdabdf
```

使用前请按 `docs/DEPLOY.md`「Verify a release」校验签名。

本版把用户门户里剩下的 v1.4.0 样式全部换成新的外观，并让苹果设备直接用系统字体。

## 苹果设备用苹方，不再下载字体
iPhone、iPad、Mac 直接用系统自带的 SF 与苹方显示，一个字体文件都不下载；Windows、安卓、Linux 照旧用 HarmonyOS Sans。

## 仪表盘
- 教程挪到左栏流量图下面（宽栏里标题完整显示），公告挪到右栏接入配置下面。

## 提示条与弹窗
- **提示条**：移到右上角（顶栏下面），改成黑底白字的小条（深色模式反过来），成功 / 失败图标不带底色。
- **弹窗**：圆角收小、加一圈细边，背后的遮罩更淡、不再模糊；底部按钮是胶囊、靠右。
- **确认框**（重置订阅、退出所有设备等）：「会发生什么」改成细线清单；确认按钮是黑色实底，只有删除这类不可挽回的操作用红色。
- **公告详情**：标签与仪表盘一致（彩色字，不铺底）。

## 订单详情
- 进度改成三段细线 + 步号（走过的黑色、当前蓝色、没到浅灰），不再是绿色对勾和圆圈。
- 状态是小圆点 + 字，取消订单是胶囊按钮；付款结果的摘要在细线之间。

## 文档文章
- 去掉了卡片：正文直接在页面上，宽度适合阅读；右侧「本页目录」「同类文档」是小标题 + 左侧细线的列表，当前项细线变蓝；上一篇 / 下一篇在上下细线之间。

## 去掉其余「浅色底 + 彩色字」
- 所有徽章（提现、返佣、工单优先级与状态、已验证）改成状态色小圆点 + 字。
- 确认订单的周期、支付方式，新工单的优先级：选中项是黑色描边或黑底，不再是浅蓝底。
- 换套餐的作废确认、余额抵扣、各种说明与提示块、登录页的提醒：都在上下细线之间。
- 「重置订阅」按钮不再是橙色；菜单里「退出登录」悬停不再是浅红底；付款结果的大图标不带底色圈。
