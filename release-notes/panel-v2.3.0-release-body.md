> **可以从 v2.2.x 原地升级**（`akari-ctl upgrade`，无需重装）：本版没有数据库迁移，升级前安装器会先备份。
>
> **节点：不需要升级 agent。** 协议号仍为 8，v0.6.x 的 agent 照常工作；建议节点用 agent v0.6.3。

## 安装

```
curl -fsSL https://github.com/akari-projectX/akari-panel/releases/download/v2.3.0/install.sh | sh
```

支持 Debian 12/13、Ubuntu 22.04/24.04；Docker 部署见 `docs/DEPLOY.md`，镜像（`deploy/.env` 的 `AKARI_IMAGE`）：

```
ghcr.io/akari-projectx/akari-panel:2.3.0@sha256:<发布后填入 digest>
```

使用前请按 `docs/DEPLOY.md`「Verify a release」校验签名。

---

本版主要是用户门户的界面打磨（仪表盘、商店、提示与弹窗），另有两项小功能。

## 新功能
- **套餐说明支持 Markdown**：后台套餐「说明」可以写 `**粗体**`、`- 列表`、链接；第一段显示在套餐名下面，列表项在门户里带勾显示。说明由面板统一渲染，写进去的 HTML 一律当文字显示，不会生效。已有的说明不用改，显示与以前一致。
- **注册后提示添加通行密钥**：用密码注册成功后第一次进入仪表盘，提示「为了保证您的账户安全，请添加通行密钥。」（下次一定 / 添加）。站点未启用通行密钥或浏览器不支持时不提示。

## 门户：仪表盘
- 顶部改为大号「剩余流量」+ 分格进度条，右侧列出套餐到期、在线线路、余额（可提现）、速率。
- 近 7 日流量图改为黑白配色。
- 「订阅内的线路」改为表格：国旗、状态、延迟、负载、倍率；鼠标停在国旗上显示地区名。
- 各类提醒（服务已暂停、待支付订单、邮箱未验证、工单回复、公告）改为页标题下的一行行胶囊，按紧急程度排列；除「服务已暂停」外都可以点 × 关闭：公告 = 标为已读；工单 = 直到客服再次回复；待支付 = 这一笔订单不再提示（订单页照常显示）；邮箱 = 本次登录不再提示。

## 门户：商店与下单
- 当前套餐区改为「N 天后到期」+ 本期流量进度，右侧列出到期、速率、余额；「流量用完？买重置包」一点直接打开重置包的确认订单（页面下方的「流量重置包」栏已去掉）。
- 套餐卡片保持原来的样式，一行最多 3 张，多的换行。
- 「用余额抵扣」从商店页移到确认订单对话框里，每笔订单单独选择，并列出原价、各项抵扣与还需支付；余额足够时按钮为「确认购买」，直接开通。购买时长选项显示扣余额之前的价格。

## 门户：其他
- 所有对话框不再带图标，统一为标题 + 说明。
- 第一次进入网站后点开对话框不再等 1–2 秒（对话框代码在空闲时与鼠标悬停时预先下载）。

## 节点安装
- 开启 BBR 时立即把默认路由网卡的队列切换为 fq，不需要重启；卸载时恢复。
