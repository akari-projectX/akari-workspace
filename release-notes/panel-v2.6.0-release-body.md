> **可以从 v2.5.x 原地升级**（`akari-ctl upgrade`，无需重装），升级前安装器会先备份。
> 本版有一个数据库迁移（`0009_default_guides`），启动时自动执行：只在知识库还是空的时候写入四篇默认教程，已有教程的站点什么都不变。
>
> **节点：不需要升级 agent。** 协议号仍为 8，v0.6.x 的 agent 照常工作；建议节点用 agent v0.6.3。

## 安装

```
curl -fsSL https://github.com/akari-projectX/akari-panel/releases/download/v2.6.0/install.sh | sh
```

支持 Debian 12/13、Ubuntu 22.04/24.04；Docker 部署见 `docs/DEPLOY.md`，镜像（`deploy/.env` 的 `AKARI_IMAGE`）：

```
ghcr.io/akari-projectx/akari-panel:2.6.0@sha256:REPLACE-WITH-THE-RELEASE-DIGEST
```

使用前请按 `docs/DEPLOY.md`「Verify a release」校验签名。

---

本版给用户门户换了字体与配色，重做了顶部菜单，把整个门户的交互与动效统一成一套，并给新站点带上四篇默认使用教程。

## 字体：HarmonyOS Sans SC
- 所有平台显示同一套字形，Windows 上不再落到微软雅黑。
- 字体按字切成小文件，浏览器只下载页面上真正出现的字；字体下载完之前先用系统字体显示，不会白屏等字体。

## 配色：中性白 + 亮蓝
- 浅色：纯白底、近黑正文、中性灰辅助色，强调色是亮蓝。
- 深色：中性近黑底、浅亮蓝强调。

## 顶部菜单
- 菜单改为「总览 · 套餐 · 节点 · 指南 · 支持 · 更多」，每项前面一个线条图标，字重统一为中粗，切换时文字不再跳动。
- 不常用的「流量明细 · 账单 · 动态」收进「更多」下拉，每项带一行说明；手机菜单里八项全部平铺。
- 页面标题跟着改名：套餐、流量明细、账单、支持、使用指南。**网址不变**，旧链接照样能打开。

## 交互与动效（全站统一）
- **会滑动的选中项**：时间范围、筛选、标签页、外观与语言开关，选中时底色块平滑滑到新的一项，和顶部菜单下面那道线是同一种手感。
- **下拉弹层**：头像菜单、手机菜单、「更多」、订阅区的小菜单、表单里的下拉选择，外观与打开动画全部一致；下拉箭头打开时会转过来。
- **按下反馈**：按钮按下时轻微缩小，列表行按下时变色；菜单与切页的关闭动画缩短到 60 毫秒，操作更跟手。
- **手机浏览器**：去掉了双击缩放的点按延迟；触屏上小图标按钮的可点范围扩大到约 44 像素；适配刘海屏的安全区；iPhone 上点输入框不再自动放大页面。
- 系统打开「减少动态效果」时，以上动画全部直接到位。

## 默认使用教程
新站点（或从没写过教程的站点）的知识库自带四篇客户端教程，中英双语，站长可以在后台随意修改或删除：
- Windows、macOS：Clash Verge Rev
- iPhone 与 iPad：Shadowrocket
- Android（含可以装安卓应用的鸿蒙手机）：Clash Meta for Android

每篇都是「安装客户端 → 导入订阅（一键或手动）→ 开始使用 → 常见问题」。分类名与仪表盘「按平台查看教程」对得上，点哪个平台就进哪篇。
