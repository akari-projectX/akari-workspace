# 风险分级与常见缺陷清单

> 来源：原 `OPUS-GUIDE.md` §4.3 / §4.4（2026-10-01，源自 R1–R14；原文已移到 `archive/`）。2026-10-07 按当前代码更新了表名与锁序。
> 用法：每个 T1 brief 必须附上本清单；worker 开 PR 前逐条自查，并在 PR 正文写明已自查。与 `akari-panel/CLAUDE.md` 冲突时以后者为准。

## 风险分级

| 级别 | 范围 | 要求 |
|---|---|---|
| **T1** | 资金 / 计费、控制协议、并发与收敛、认证鉴权、证书、安全边界、授权（套餐 → 节点组 → 入口） | 附本清单；单元测试 + 真库测试；新接口有 smoke 断言；合并前加 `full-ci`；lead 逐行审 |
| **T2** | 运维、CI、部署、API 小改、测试基础设施、前端 | lead 审 diff，CI 全绿后合并 |
| **T3** | 文档、注释、配置默认值 | lead 直接改或随其他 PR 带上 |

## 常见缺陷清单

1. **提交前先通知**：通知必须由 DB 触发器在同一事务内发出，handler 提交后什么都不用做。
2. **旧读覆盖新写**：读 DB 前取票据；同一会话的读取与下发串行化。
3. **锁序反转**：全局顺序 `entitle::lock` → servers（`ORDER BY id FOR UPDATE`）→ nodes → users → entrance_users（详见 `akari-panel/CLAUDE.md`"收敛"）。
4. **被攻陷节点导致内存 / 计费无上界**：成员资格校验、条目上限、按节点索引，不得全表扫描。
5. **计费多计**：只允许少计；差值只能在 SQL 里用 `RETURNING OLD/NEW` 计算，内存不存 pending。
6. **拒绝响应不同构**：一切拒绝走 `reject::not_found()`：404、空 body、无安全头、无 `X-Request-Id`。
7. **删除 / 禁用没有在所有路径生效**：API、CLI、到期扫描、reconcile、手写 SQL——靠触发器兜底。
8. **多实例下的进程内假设**：防重放、限速、在线状态都走 DB / Valkey，不用进程内缓存。
9. **时间戳倒退**：`now()` 是事务开始时间；到期判断只用 DB 时钟；日界按站点时区。
10. **NULL 让上限失效；取整超过上限**（GCRA 逐行 floor）。
11. **秘密进日志**：后台前缀、订阅路径与 token、enrollment / 安装 token、私钥、主密钥派生物一律不进日志、trace、指标标签；路径用 `web::redacted_path`。
12. **失败被当成收敛**：agent 应用失败不前移持有版本；Ack `ok=false` 不算收敛。
