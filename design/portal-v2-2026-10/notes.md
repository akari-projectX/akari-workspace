# 门户 v2 样稿 · 克制排版风（2026-10-22）

三页定风格：`dashboard.html`、`shop.html`、`login.html`，入口 `index.html`。
状态用网址 `#` 打开：`dashboard.html#notices`（待付款 + 流量不足）、`#usermenu`、`#menu`（窄屏菜单）、
`shop.html#confirm`、`login.html#register`。截图在 `screenshots/`（1440 / 390，浅 / 深，整页）。

## 原则
1. 层级靠字号、字重、留白和 1px 细线；不给每个区块套卡片。带边框的只有：公告横幅（3px 标签色左边）、套餐卡片、对话框、表单控件。
2. 品牌蓝是唯一强调色：主按钮、链接、当前导航下划线、图表。绿 / 琥珀 / 红只表示状态，且总配文字。
3. 关键数字大而清楚（34px / 600，tabular-nums），单位小一号灰色，解释放在下一行。
4. 单色线性图标（lucide 风格，1.75px），只在帮助识别时用；不用彩色图块、问候语、环形图、渐变、阴影堆叠。
5. 去掉填充文案：页面副标题写真实信息（如“标准 Pro · 月付 · 每月 1 日重置流量”）。

## 导航决定
- **桌面**：纯文字顶栏，当前项 600 字重 + 2px 品牌蓝下划线（贴在顶栏底线上），无胶囊、无图标。
  `仪表盘 商店 线路 用量 ｜ 公告 文档 工单` —— 7 项平铺，细竖线把“用服务”和“看信息 / 求助”分成两组；公告带未读点。
  `订单 钱包 邀请 账户设置 退出` 收进右侧邮箱下拉，下拉里直接显示“1 笔待付款 / ¥128.50 / 返利 10%”。
  理由：11 个页面里 4 个是账户 / 资金类，挂在“我”下面符合直觉（GitHub、Stripe 同理）；其余 7 个是日常使用的，
  中文两字标签平铺 7 项在 1024px 以上不拥挤，因此不再需要“更多”。Logo 与导航之间留 56px。
- **窄屏（<960px）**：顶栏只有 Logo + “菜单”。菜单是从顶栏下方铺满全屏的纯文字列表（不是浮动卡片），
  分“服务 / 账户 / 偏好”三组，行高 46px、16px 字号，右侧灰字给出状态（6/8 可用、2 条未读、1 笔待付款）；
  底部是主题与语言的文字切换和退出。没选底部标签栏：7 个一级页放不下，挑 4–5 个又回到“藏一半”的老问题。

## 页面要点
- 仪表盘：提醒（待付款、流量不足）不做彩色卡片，作为细行插在关键数字上方，图标单色、流量不足为琥珀；同时剩余流量进度线变琥珀。
- 线路：地区码（HK / JP / SG / US）等宽灰字代替国旗 emoji；状态 = 色点 + 文字；倍率纯文字右对齐。
- 7 日流量：HTML/CSS 堆叠柱（下行品牌蓝、上行浅阶），虚线网格、顶部总量标签、悬停提示，今天加粗。
- 商店：沿用已批准的卡片概念；当前套餐蓝框 +“当前套餐”文字，推荐用实底小标签；只有当前套餐卡用主按钮。
- 确认订单：窄屏变底部抽屉，操作栏吸底。
- 登录：无插画；Logo → 登录 / 注册 文字标签 → 表单；通行密钥作为次按钮放在“或”之后。
